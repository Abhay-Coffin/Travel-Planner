# 🌍 Travel World — AI Powered Travel Planning Platform

## 🚀 Overview

Travel World is a modern AI-powered MERN travel planning platform designed to help users plan trips intelligently with real-time travel insights, AI itinerary generation, live maps, booking management, payment integration, expense prediction, and conversational AI assistance.

The platform combines Artificial Intelligence, real-time APIs, modern UI/UX, and secure full-stack architecture to deliver a production-ready travel planning experience.

# 🧠 AI Architecture

## AI Workflow

1. User enters travel preferences.
2. Backend sends structured prompt to AI model.
3. AI generates itinerary and expense prediction.
4. Frontend renders structured travel plan.
5. AI assistant stores conversations persistently.

# ⚙️ Backend Setup

```bash
cd backend
npm install
npm run dev
```

## Backend Environment Variables

```env
PORT=4000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
GROQ_API_KEY=your_groq_key
RAZORPAY_KEY_ID=your_key
RAZORPAY_KEY_SECRET=your_secret
EMAIL_USER=your_email
EMAIL_PASS=your_app_password
```
